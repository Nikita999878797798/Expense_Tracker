# Expense Tracker (Трекер расходов)

Автор: Крестников Никита Андреевич

## Описание программы

Expense Tracker — это desktop-приложение с графическим интерфейсом для отслеживания личных расходов. Программа позволяет:

- Добавлять расходы с указанием суммы, категории и даты.
- Просматривать все расходы в таблице.
- Фильтровать расходы по категории и диапазону дат.
- Автоматически подсчитывать сумму расходов за выбранный период.
- Удалять ненужные записи.
- Сохранять данные в JSON-файл и загружать их при следующем запуске.
